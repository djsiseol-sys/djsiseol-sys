# 시설 예약 관리대장

지자체 체육시설(충무체육관·한밭체육관·야구장) 예약을 월별 달력으로 관리하고,
조례에 따른 이용료를 자동 산정하는 **부서 내부용 도구**입니다. 시민 대상 공개 서비스가 아닙니다.

- 주소: https://djsiseol-sys.github.io/djsiseol-sys/
- 담당자 1명이 등록·수정하고, 나머지 직원은 조회만 합니다
- 개인 성명·연락처를 담지 않는 구조입니다 (신청 단체명만 기록)

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 화면·계산·저장이 모두 들어 있는 단일 파일. 빌드 도구 없음 |
| `배포안내.md` | GitHub Pages 로 올리고 주소를 켜는 절차 |
| `CLAUDE.md` | 코드 구조와 지켜야 할 규칙 (작업을 이어받을 때 읽는 문서) |

`index.html` 을 내려받아 브라우저에서 바로 열어도 똑같이 동작합니다.
